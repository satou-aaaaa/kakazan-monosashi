# kakazan-monosashi

活火山の物差し：火山の名前と、いちばん新しい噴火の年代を見て、活火山かどうかを見分ける1日5問の学習ゲーム（防災シリーズ BS6「1万年の物差し」）。

- 遊ぶ：<https://satou-aaaaa.github.io/kakazan-monosashi/>
- 活火山は「概ね過去1万年以内に噴火した火山及び現在活発な噴気活動のある火山」（気象庁「活火山とは」）。日本の活火山は111。
- 1万年は人の一生（約100年）の100倍。いま静かでも、1万年以内に噴火していれば活火山です。
- 噴火の年代は、気象庁「日本活火山総覧（第4版）」と各火山の「有史以降の火山活動」、産総研の資料の目安です。「約〇年前」には数百年の幅があり、調べが進むと変わることがあります。
- 噴火警戒レベルは扱いません（噴火警戒レベルよみ funka-level）。
- 記録は遊ぶ人のブラウザ（localStorage）だけ。外へ記録を送りません（外から読むのは文字の形の Google Fonts だけ）。

検査：`node qa/run.mjs`（AGENTS.md）
